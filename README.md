# Pennywise — Expense Tracker

Pennywise is a personal expense tracker built with React, TypeScript, and Vite.
It helps users manage their income and expenses, monitor their monthly budget,
and understand their spending habits through visual summaries.

## Features

- Add and manage income and expense transactions
- Track total income, expenses, and balance
- Set a monthly spending budget
- Monitor remaining budget and spending progress
- Search and filter transactions
- View spending summaries with charts
- Save transactions and budget data using browser localStorage

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Recharts
- Browser localStorage
