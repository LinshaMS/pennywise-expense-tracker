
# Pennywise — Expense Tracker

Pennywise is a personal expense tracker built with React and TypeScript. It helps users track income and expenses, manage a monthly budget, and understand their spending habits through visual summaries.

## Features

- Add income and expense transactions
- View total income, expenses, and balance
- Set and monitor a monthly budget
- Track remaining budget and spending progress
- Search and filter transactions
- Visualize financial summaries with charts
- Save transactions and budget settings using browser localStorage

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Recharts
- Browser localStorage

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/LinshaMS/pennywise-expense-tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd pennywise-expense-tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Data Storage

Pennywise uses browser localStorage to save transactions and budget settings on the current browser. It does not currently use a remote database.
